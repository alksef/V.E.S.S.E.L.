# Использование

Запустите собранный `vessel.exe`. Окно прозрачное и находится поверх остальных.
Щелчок по иконке трея показывает или скрывает окно. Закрытие окна и Escape
скрывают его; для завершения процесса выберите «Выход» в меню трея.

Перемещайте окно за верхнюю ручку или с Alt/Shift и левой кнопкой мыши.
Панель управления тоже можно перемещать. Кнопки приближения меняют масштаб.

| Клавиша | Действие |
|---|---|
| F | Следующий план камеры |
| H | Показать / скрыть панель |
| B | Моргнуть |
| N / W / S | Кивок / взмах / пожать плечами |
| T | Демонстрация липсинка |
| X | Переключить пропуск кликов через окно |

На первом запуске нажмите **Choose VRM…** и выберите `.vrm` (VRM 0.x или 1.0).
Приложение сохраняет локальную копию и загружает её при следующих запусках.
Исходный файл после выбора можно переместить. Для смены модели снова нажмите
**Choose VRM…**; пересборка не нужна. Отмена выбора сохраняет текущую модель,
ошибка загрузки или сохранения также оставляет предыдущую модель активной.

Модель не загружается из сети, не включается в exe и не отправляется backend:
по WebSocket передаётся только имя выбранного файла в сигнале готовности.
Используйте модель с подходящими для вашего сценария условиями.
В browser-режиме модель сохраняется отдельно для адреса страницы; модель,
выбранная в браузере, не меняет модель настольного приложения.

Если аватар не готов, проверьте `http://127.0.0.1:8765/health`:
`renderer_connected` показывает подключение окна, `model_ready` — загрузку модели.

Контракты внешнего управления: [интеграции](../integrations/README.md).
