# Roadmap

Планы хранятся в `active/`, завершённые направления — в `completed/`.
Формат документа: цель, статус, оставшаяся работа, критерий готовности;
для завершённого — краткий результат и ссылки на актуальную документацию.
Новые каталоги и отдельные документы создаются по мере необходимости.

по направлениям; завершение кода не заменяет ручную проверку desktop-сценариев.
