# 004 — Иконка и управление из трея

Статус: in progress. Требования согласованы 16 октября 2026.

## Цель

Добавить оригинальный узнаваемый знак VESSEL и безопасный способ вернуть
управление после включения пропуска кликов.

## Этапы

- [x] Добавить переключатель «Пропускать клики» в меню трея.
- [x] Синхронизировать переключатель панели и отметку меню через backend.
- [x] Восстановить состояние пропуска кликов из backend при перезагрузке интерфейса;
      показывать ошибку переключения в статусе панели.
- [x] Обновлять состояние панели после успешного переключения; описать возврат через трей.
- [x] Создать SVG-знак: V в форме сосуда с искрой внутри.
- [x] Экспортировать ICO с размерами 16 / 20 / 24 / 32 / 48 / 64 / 128 / 256 px.
- [x] Проверить читаемость иконки на светлом и тёмном фоне в размере 16 / 20 / 24 / 32 px.
- [ ] Проверить в desktop включение с панели, отключение из трея и восстановление окна.

## Критерий готовности

Новая иконка используется в сборке и трее. После включения пропуска мышь проходит
через окно; выключение из трея возвращает доступ к панели. Отметка меню и состояние
кнопки совпадают. Показать / скрыть и «Выход» сохраняют своё назначение.
