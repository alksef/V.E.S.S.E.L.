# 002 — Доработка панели и управления окном

Статус: in progress. Требования согласованы 16 октября 2026.

## Цель

Сделать панель компактной, упростить управление камерой и исправить поведение окна.

## Этапы

- [x] Перенести панель в правый нижний угол.
- [x] Свернуть панель в квадрат; щелчок раскрывает, перетаскивание двигает окно.
- [x] Убрать из панели имя модели и адрес backend; сохранить короткий статус и ошибки.
- [x] Поставить Zoom − / Zoom + в строку Face / Bust / Half / Full.
- [x] Убрать дублирующую кнопку Full body из заголовка.
- [x] Заменить Close на «Свернуть в трей» с явным скрытием окна.
- [x] Убрать действие по Escape.
- [x] Ограничить высоту панели с прокруткой и учесть рамку и отступы в размере кнопок.
- [x] Проверить в browser-режиме раскрытие, свернутый квадрат, расположение зума
      и отсутствие действия Escape; сборку frontend и 23 существующих теста.
- [ ] Проверить в desktop: квадрат, щелчок после перетаскивания, скрытие и восстановление.
- [ ] Проверить панель на небольшом размере окна и сохранение масштаба.

## Критерий готовности

В свернутом виде виден только квадрат. Перетаскивание не раскрывает панель.
Камера управляется из одной строки. Escape не меняет окно. Сворачивание сохраняет
работающее приложение, восстановление доступно из трея.
